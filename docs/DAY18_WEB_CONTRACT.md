## 当前边界

- 前端位于 `WebApp`，使用 React、TypeScript、React Router 和 Vite；本地开发端口固定为 `127.0.0.1:59318`，`/api` 与 `/health` 代理到后端 `127.0.0.1:9300`。
- 登录使用 `POST /api/v1/auth/login` 获取令牌，再用 `GET /api/v1/auth/me` 获取服务端确认的身份和工作空间角色。令牌只存内存，刷新后需重新登录。
- 页面路由可见性只是交互控制，不是授权边界；业务接口仍须由后端校验身份、角色及工作空间。
- 页面按步骤接入；尚未接入的页面明确显示占位状态，不能当作数据联调或端到端验收成果。
